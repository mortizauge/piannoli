# Piannoli

Piannoli is a customizable Android emulation frontend forked from [Cannoli](https://github.com/CannoliHQ/cannoli), with controller and touch navigation. Games run through external emulators, including RetroArch; the built-in emulator and its in-game menu have been removed.

Scrape game and system artwork in the app through SteamGridDB, individually or in bulk. Add your API key through **Setup scrapers**. Choose custom game, folder, and category images, adjust their appearance, or hide artwork entirely.

Organize your library with collections, per-list sorting, hidden games, and support for alternative system-folder names and file-type filters. Reorder Recently Played, Favorites, and Collections among themselves, and pin Android apps for easy access. Automatic library refresh runs quietly in the background, notifying you of added or removed games and any refresh issues.

Customize controls, keyboard input, navigation sounds, haptics, and animations. Improved scrolling, search, and touch feedback make browsing smoother, while your browsing position is preserved when returning from a game. Original Xbox games can launch through X1 BOX or hakuX. RetroAchievements uses supported external emulators; obsolete offline-set management has been removed.
